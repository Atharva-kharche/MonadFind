# Contributing to MonadFind

Thank you for your interest in contributing to MonadFind!

## Development Setup

To get started with local development:

1. Fork the repository
2. Install dependencies: `yarn install`
3. Run the Next.js frontend: `yarn start`
4. Make your changes in a new branch

## Testing

Ensure that all smart contract tests pass before submitting a pull request:
```bash
yarn workspace @monadfind/hardhat test
```

## Pull Requests

1. Keep PRs focused on a specific feature or bug fix.
2. Ensure ESLint and TypeScript checks pass.
3. Provide a clear description of the changes in the PR.

Thank you!
